# Competitive Pricing Dashboard UI

Professional dashboard showcasing the Competitive Pricing Multi-Agent System — a two-tier AI architecture with deterministic safety constraints.

## Features

✅ **Hero Summary** - Key metrics (60% savings, 107 tests, 12% margin floor, 800 SKUs)  
✅ **Architecture Diagram** - Visual flow showing LLM intelligence + code safety  
✅ **Live Decision Feed** - Recent pricing decisions with margin safety validation  
✅ **Cost Comparison Chart** - Two-tier vs single-model cost analysis  
✅ **Tech Stack Display** - Technologies used in production system  
✅ **Professional Dark Theme** - Glassmorphic design with purple/pink/orange accents  

## Design Philosophy

- **Data-focused**: Proof-of-work dashboard, not a marketing page
- **Technical depth**: Shows real system architecture and decisions
- **Safety emphasis**: Highlights margin check overrides (LLM vs Code)
- **Mature aesthetic**: Enterprise/business-grade, not flashy or gaming-style

## Tech Stack

- **React 18** - UI framework
- **Tailwind CSS** - Styling with custom dark glassmorphic theme
- **Recharts** - Cost comparison visualization
- **Framer Motion** - Smooth animations
- **Lucide React** - Icon system
- **Vite** - Build tool and dev server

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Development

The dev server runs on `http://localhost:3000` with hot reload enabled.

## Data

All data is realistic mock data based on the actual project:
- SKU codes (LAP-0042, MOU-0156, etc.)
- Real pricing decisions (MATCH, UNDERCUT_50, HOLD)
- Actual cost calculations (Groq API pricing)
- Authentic margin safety overrides
